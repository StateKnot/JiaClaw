# 模型按需读取已加载技能

管理员可显式启用：

```toml
[tools.skill_read]
enabled = true
```

缺省为 false，现有关键词激活和显式 `enabled_skills` 正文注入保持原行为。启用后不再按关键词自动注入正文；每轮目录仅包含名称、描述和正文 SHA-256。模型必须通过获准的 `skill_read` 读取需要的正文，显式 `enabled_skills` 仍代表调用方直接选定并注入技能。`auto_skills=false` 不关闭摘要目录或获准的读取工具，它只控制旧关键词激活。

`skill_read` 仅接受目录中完整的 name 和小写 64 字符 `content_sha256`，禁止未知字段。名称是已加载技能名称，不是文件路径。工具读取当前已加载注册表中的正文快照，不打开磁盘、参考文件、URL 或模型凭据；最多 128 KiB，且 JSON 字符串序列化不得超过原生循环共享的 256 KiB 输出预算，超限在成功交付前拒绝、不截断。读取选择与版本比较在同一个短读锁中完成。改变磁盘文件但未重载不会改变已加载版本；重载替换正文或移除技能后，旧 hash 请求失败，不静默返回新版本。失败是本地只读 `no_effect`，可反馈给模型，提示应从新一轮目录重新选择。成功取得的原版本不会因稍后的重载追溯撤回。

开关只注册工具；每个请求仍遵守原 `enabled_tools`、原生工具 Schema/整批准入、工具调用数和输出预算。技能正文不能扩大权限；文本中的命令或新工具名不会自行注册或执行。管理员应审核技能来源与正文；SHA-256 只绑定正文版本，不证明来源可信、签名或内容安全。租户协议仍只开放原 datetime_now/json_query，不能把 standalone 能力外推为跨租户技能授权。

本能力覆盖模型选择完整正文和热加载版本一致性。参考资源按需读取、安装/更新/撤销、来源锁文件、经验生成与跨租户授权仍分别待实现。真实 CLI/HTTP 原生两轮协议测试只能证明应用接线，不认证真实供应商的技能选择质量。
