# PDF 可提取文字加入任务草稿

工作台支持 standalone、个人 Key JSON 和个人 Key 预览三种原任务入口。选择 PDF 后点击“提取并加入草稿”，原 FileReader 完整捕获一个文件，在本页独立 Worker 中消费本地固定 PDF.js，逐页流式提取文字。只有用户显式点击原发送按钮、重新选择本次允许的工具，才进入原授权、UUID、模型、hold、收据和下载流程；选择或提取文件不调用模型。

## 完整输入与适用范围

- 文件名最多128 UTF-8字节，拒绝 Cc、Bidi_Control、slash/backslash，只接受 `.pdf`；原文件1..1048576 bytes、PDF1.0–1.7/2.0头、1..32页。
- 全部页面按文档页序提取；任一页没有非空可提取文字、加密、XFA、损坏或无法解析时整次拒绝。页标记与提取文本合计最多16384 UTF-8 bytes，完整草稿含文件名、页数和原文件 SHA-256 最多32768 bytes，边界允许、超限拒绝，不截取或发送部分资料。
- 这是 PDF.js 的文字层提取，空白可能被 PDF.js 规范化，文字按其内容流顺序排列；不做 OCR，不保留视觉版式、图片、链接、交互表单或表格结构。有文字的页面仍可能包含未提取的图片内容。导入前后必须核对原 PDF；不能据此认定扫描图片、图表、字体映射或全文语义已完整识别。SHA绑定本次捕获的原字节，不是签名、来源真实性或草稿编辑后的认证。
- 不加载外部字体/CMap/WASM。需要外部资源才能提取的 PDF 不受支持；不会因缺失资源改为联网下载。原文本资料入口和它自己的 UTF-8/BOM/换行规则保持独立兼容。

## 所有者与权限

读取、来源摘要、资源加载和提取共用同一个五秒绝对截止，每次异步返回及赋值前重新核对。一个当前草稿操作最多一个实际解析 Worker，不启用主线程 fake-worker 后备；结束、失败、超时或身份取消均终止 Worker。定时器不是 OS 内存沙箱或主线程物理硬抢占；迟到回调仍拒绝赋值。该截止不延长原模型、工具或网关期限。

完整捕获只调用一次原 FileReader；没有后台 PDF 上传、第二读取引擎、搜索/Store/向量库、模型工具或自动学习。SDK/worker模块通过本服务公开固定同源资源 GET 加载，不是字面零网络。Worker 的 CSP 为 `connect-src 'none'`，不加载文档 URL、不渲染、不运行 PDF JavaScript/XFA/附件，所有 PDF.js 原始异常只映射为本地固定错误，不公开 PDF 正文或解析器原文。

只读、未连接、未选会话、已有 active 任务或 busy 状态不能导入；身份、会话、选择代次或原草稿改变后，迟到读取/摘要/Worker结果不得恢复私人 DOM 或派发模型。导入不增加工具授权、修改旧任务事实、解除未知 hold、自动重试或继续。资料中的文字或标记不能认证 prompt injection 隔离。

原 PDF 留在本机，不上传。发送后文件名、原字节摘要和提取文字会作为原消息进入本用户配置模型与原持久会话，可能增加输入费用；关闭页面、断开或清选择不删除已加入草稿、已提交消息、供应商或备份。原物理回复下载合同保持。
