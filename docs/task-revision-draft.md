# 按已保存的修改说明准备新任务

本批消费原任务结果评价与原工作台草稿，提供可实际审阅和发送的修订任务。它不是再次实现反馈保存，也不是继续未知的原任务。

只有当前已核对的 completed、无 active、正文保留的 tracked 原 UUID，且当前评价为 needs_changes、保存说明非空白时才可准备。需要完整权限 Key、原会话仍被选中、当前消息草稿为空；readonly、运行中、needs_review、purged、未核对、未保存说明均拒绝。

用户默认未确认。明确确认绑定原 UUID、会话、请求摘要、评价 revision、完整回复和已保存说明。点击后复用原有界、15秒超时的认证 receipt GET 和原验证器，再检查身份、原 attempt、选中会话、空草稿及全部绑定字段。修改说明或回复变化时取消确认并要求重新核对；迟到旧身份、会话或已改变的草稿不得覆盖当前页面。不自动重试、轮询、恢复旧身份或发模型请求。

完整回复和说明进入新草稿，包含原 UUID 和评价 revision，BOM、TAB、空白原样，CRLF/CR 统一 LF；整份含 framing 最多32768 UTF-8字节，exact允许，超限或非法 Unicode、不支持的 ASCII控制字符整次拒绝，不截取。原回复来自完整 receipt，不用显示截断文字、实时预览、工具正文或额外会话 history。标记只帮助阅读，不认证 prompt injection 隔离。

成功后结束本页原请求跟踪，保留原任务、评价、会话和原查询/占用政策；不发取消、审核、feedback写入或重新提交原 UUID。清除本页评价与确认，并取消所有工具、技能及来源授权选择。新草稿可编辑，必须重新选择本次工具并显式点击原发送按钮，才按原准入生成新 UUID 和模型请求。旧任务/结果不重放；未知效果不因准备草稿而解除或继续。

发送时完整回复和说明将交给本用户配置的模型并进入原会话历史，可能增加输入费用；原历史仍独立进入上下文。断开/身份切换清本页私人草稿，刷新不保存草稿；原服务端任务、评价、供应商记录、下载和备份不因此删除。没有新读/搜索/Store/向量库/模型工具、权限或后端端点，也没有自动学习、质量保证或 StateKnot durable/审批继续/Agent浏览器认证。

standalone、tenant JSON 和 tenant preview 都沿原权限、GET、草稿和发送通路验收。真实模型 fixture 的两次成功只认证接线与一次新任务，不认证供应商、业务修订质量、经验学习或实际付费模型。
