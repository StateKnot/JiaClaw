# 工作台会话资料迁移

复用已有 `/api/sessions/:id/export?format=json` 和 `/api/sessions/import`，让用户下载完整会话资料，或明确审阅后将本机 JSON 会话资料导入一个全新会话。没有新存储、模型工具、历史搜索或执行恢复引擎。

本批只开放 standalone 管理 Token 工作台。个人 Key 网关继续原入口范围，不因前端扩展导入或导出权限。迁移的是消息资料，不是任务、工具效果、原请求身份、模型账本、评价、定时任务、记忆、配置或备份恢复；原 tracked HTTP 收据与 hold 保留，不重放。

## 下载

显式确认当前完整会话可能含私人资料，再以当前身份 GET 原 export。捕获时绑定身份及选中会话，禁止正在跟踪任务时下载；最多 2 MiB 完整 JSON。必须为原 id 和完整 `messages` 数组，每项仅 `role` / `content`，角色限 system/user/assistant，字符串须合法 Unicode；不以页面显示的末51条或截断正文生成文件。0条消息有效。捕获、校验和浏览器保存请求共15秒，超限整次拒绝，不截取。下载名只用随机 UUID；浏览器保存请求不等于已落盘成功。身份或选择迟到不触发下载，成功后撤销 Blob URL。下载不延长会话 TTL，原导出 GET 仍可按既有规则清理过期记录。

## 导入

用户明确选择1..262144字节 `.json`，复用原 FileReader 完整捕获，5秒绝对截止、严格 UTF-8。只接受本工作台导出的紧凑JSON（可带首尾空白）`{id?, messages}`；拒绝非规范重编码及重复字段，不自建JSON解析器。完整数组最多51条，消息严格同上；拒绝额外字段、非法 Unicode，超过51条整次拒绝，避免原导入压缩规则丢弃资料。原导入路径新增明确 `preserve=true`：最多51条整份保留，超过上限拒绝；缺省仍沿原50条压缩规则，网关不开放该参数。原id仅作资料来源展示，永不作为写入目标；原文件保留，服务端不接收文件名。

本页展示完整角色和正文（textContent），用户核对并明确勾选后才能提交。读取文件、预览和勾选均不发API或模型请求。点击提交生成一次随机 UUID，固定目标后仅一次 POST `format=json&id=UUID&overwrite=false&preserve=true`；原配置仍可比前端更严格。请求JSON编码最多512KiB，不覆写原会话；不接受部分或修改后的成功回执。最终原 GET 完整核对后才选中新会话，不自动调用模型。导入资料在服务端按原会话规则保存，后续显式发送会将资料交给配置模型，可能增加费用；原 standalone 旧式对话工具范围仍由管理员配置决定，资料不授予额外权限。

等待超时、响应丢失或异常回执时，保留本页目标编号，提示只读取该目标核对，不自动重发 POST、不自动换号重试、不清除服务端 hold；重新核对为独立显式 GET。查到完全相同消息才认定本次资料已保存，否则保留未知状态。用户可明确结束本页跟踪；这不删除可能已保存的会话或解除任何服务端占用。关闭页面不保留文件内容、确认或密钥，原目标编号须自行保存；不是 durable 运行恢复。

身份切换清理预览、文件选择、确认和本页跟踪；在途导入可能已写入原身份，迟到响应不能恢复私人 DOM。选中会话切换、导入文件变化或重读都会取消旧确认。原任务在跟踪、页面忙、只读或未连接时不能导入。无浏览器 storage、轮询、自动模型调用、原任务重放或管理员 hold 解除。

## 验收

独立真实 standalone HTTP/SQLite/Chromium 验证完整 JSON 物理下载、BOM/CRLF/NUL/空白与Unicode正文保留、空会话、完整51条与52拒绝、超限/坏UTF8/extra/错role/surrogate拒绝、显式预览确认前零POST、唯一新UUID/原会话不变/真实重启后的原GET、一次已写响应丢失后显式GET恢复、身份迟到与只读/网关无入口、零模型调用和零storage。固定源码、交付/发布身份与新head官方资格分别认证；原PR143完整资格仅历史，不代本批。
