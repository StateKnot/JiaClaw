# 本机管理员登记新技能

`skills register <一级目录> --repository <HTTPS来源> --revision <固定Git对象ID> --skill-sha256 <完整SKILL.md原字节SHA256> --if-manifest-sha256 <已审核原锁SHA256> --config ...` 为已有必需来源锁添加一个新目录。管理员先在配置工作区准备并审查本地技能文件与完整原字节摘要；命令只接受已存在的有效锁，目录必须尚未登记，来源参数与既有 `set-source` 具有相同的严格格式。不会联网或认证发布者。

原锁读取、原字节hash条件、目标能力读取/解析/摘要、完整候选目录检查和原子单文件发布共用既有非排队workspace writer。新记录明确 `enabled:false`；版本1转成版本2，原启用状态和全部其他来源保留，排序后最多64项。目标SKILL.md必须为单链接普通文件、有效UTF-8与合法元数据且不超过128KiB；链接、硬链接、FIFO、目录、路径穿越和无效来源均拒绝。完整候选启用目录仍受原64技能/2MiB/256条目/合作截止约束，其他未登记技能和启用正文漂移不能被登记操作掩盖。声明参考资源仍在实际按需读取时独立核验，不认证整包内容。

重复目录、过期hash、容量超限、缺锁/无必需策略、缺失或不符摘要的目标，以及候选扫描错误均非零，提交前失败保持原锁字节与inode，清理暂存。两个相同原hash的协作请求最多一个提交；hash不是单调代次或ABA检测。rename后的目录sync失败可能已提交，须先检查原磁盘策略，不自动重试。

成功返回磁盘策略和 `runtime_applied:false`；登记不会修改技能文件、自动启用、重载或改变运行表。使用新的锁hash另行 `set-enabled`，成功认证重载并GET原服务，才能确认采用该技能。登记后的停用状态允许独立审查和保留来源；不删除文件、抹除历史、取消已选择工作或撤销通用workspace文件权限。协作writer不提供独立ACL，授权文件工具和非协作管理员仍可能修改磁盘。

本批交付本地已审核技能的条件登记，不包括下载、包安装/更新/撤销事务、签名验证、锁创建、模型或HTTP写入口、跨租户授权。真实供应商与技能安装资格仍需独立证据。
