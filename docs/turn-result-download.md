# 保存任务回复

工作台的“下载完整回复 (.txt)”保存原请求收据中的完整回复，方便把任务产出带出工作台继续使用。文件是 UTF-8 纯文本；保留原字符、空白、换行与 BOM，没有额外标题、提示、工具正文或费用。文件名只使用 `jiaclaw-<原UUID>.txt`，不会将模型内容或私人会话名放进路径。纯文本不会在工作台执行 HTML；用户在其他应用打开文件时仍需按不可信模型输出处理。

只开放已核对、无活跃执行、`completed` 且结果正文仍保留的原请求。实时预览、仅收到 done、读取失败、需要人工核对、已清理正文都不能下载。页面可能截断长回复，下载仍消费完整收据，受既有2MiB回复与原有有界JSON读取上限约束。

每次点击只使用当前身份，对同一原 UUID 再执行一次原15秒 GET，并通过既有原编号/请求摘要/上下文/工具授权校验。新响应通过前旧收据不作为新文件；若正文已清理或 Key 已撤销则拒绝下载。身份切换或结束跟踪后，迟到 GET 不能启动下载。此操作不发模型请求、提交/重发任务、轮询、读取会话历史、解除 hold、调用新工具或创建服务端存储。已有只读个人 Key 可以按原查询权限保存保留的回复。standalone 与独立用户 JSON/流式请求共用原收据路径。

浏览器点击后只报告“已请求浏览器下载”，不能认证用户最终保存成功。Blob URL 在交给浏览器后撤销；页面不把正文写入 localStorage、sessionStorage 或剪贴板。下载文件可能含私人内容，由浏览器管理，断开连接、结束跟踪、服务端清理或删除不能删除用户已经下载的文件。

## 验收范围

公开验收边界为现有工作台按钮、真实原请求 HTTP GET 与 Chromium 下载的真实文件字节。沿用真实 standalone/model/SQLite 与双用户 gateway/native/model fixtures，核对实际已完成回复及模型POST/工具效果保持；预览和 final GET 屏障、Unicode回复与长回复、只读Key、撤销/身份迟到、已清理结果与响应错误分别验收。注入异常GET仅为浏览器合同负例，不冒充供应商响应或业务质量。适当回归保留原预算与断言。
