# 首用：显式验证真实模型路径

`doctor` 仍默认离线、只读，`doctor --connect` 也不发送模型请求。操作员可单独运行：

```sh
jiaclaw model-probe --config /private/config.toml --confirm-billing
```

本命令可能计费并创建/更新私有模型账本。必须明确确认、配置 `provider_type="brokerrouter"` 与 `[model_calls] enabled=true`，并先停止使用同库的服务；不自动启用账本，不使用 stub 或开发直连逃生舱。配置/key/端点/完整出站请求验证在打开账本前完成，默认环境 Key 优先规则与真实 Agent 相同。

只使用应用的 Chat 模型路由，诊断采样温度为0，输出 token 上限是 `min(该路由预算,128)`，不切换模型或自动重试。系统消息和用户消息是固定诊断指令与随机验证码，不加载工作区人格、记忆、技能、会话、MCP、embedding 或工具目录；不初始化它们的数据库。即使配置启用了这些能力，也不发送其中的内容或执行工具。这不是对整个 Agent 配置的替代检查。

出站 POST 复用现有[模型调用账本](model-calls.md)的原始操作身份、字节 hash、独占所有权和预留空间；原请求/响应最多2MiB、连接最多10秒、网络请求最多60秒，收据保存消耗同一请求期限。唯一规范的远端 UUID、精确逻辑模型、assistant/stop 与无工具、有界 JSON 必须通过原收据合同。不根据 HTTP 状态或响应错误正文自动重试。

成功输出仅包含本地 operation UUID、远端 request UUID、实际诊断模型/采样/输出预算以及 `verified`。响应在输出前已经持久保存。返回验证码不匹配时输出 `verified:false` 并非零退出，收据仍为 completed；这说明诊断指令没有完成，不等于凭据一定无效。原始模型正文和 Key 不打印，管理员可用 `model-calls result <operation_id>` 读取原私有收据。

传输、协议或持久化结果未知时保持原 hold；同库下次 probe/Agent 调用在 POST 前拒绝。SIGINT/SIGTERM 停止诊断等待，并给实际收据 owner 五秒结算时间，不重发、不继续工具；完成后仍以中断退出，须检查原收据。宽限期到期、SIGKILL或故障后的未决状态通过原账本重启合同进入 unknown，只有既有 GET-only recover 或显式人工核对可解除。SQLite/硬件同步并非物理时间保证。状态完成与命令输出/验证成功分别保留，不把中断后无输出解释为未计费。

Module 中每个已打开 probe 只能尝试一次；取消或错误后不能再用该对象重发。再次运行 CLI 是操作员明确的新请求，可能再次计费。禁止用禁用账本、换路径或删状态绕过原未知 hold。

验收要求：真实二进制覆盖明确计费确认/静态拒绝前零网络零状态、精确路由/预算/两条无私有内容消息、错误验证码的已完成收据、HTTP/身份/模型/工具/输出错误后持久 unknown 与零重发、准入事务失败前零 POST、实际 SIGTERM 等待结算、SIGKILL 重启 hold 与 GET-only 恢复。测试使用本机假网关；即使上述通过，真实供应商凭据、计费、TLS/代理、模型质量、工具任务、渠道首用和安装资格仍须分别认证。128是请求的输出 token 预算，不是费用上限或所有推理模型均能完成验证的承诺。
