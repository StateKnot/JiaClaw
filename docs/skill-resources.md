# 已声明技能参考资源读取

管理员先审核参考文件的原始 UTF-8 字节，计算 SHA-256，并在 SKILL.md 的扩展 frontmatter 声明，最多8项：

```yaml
---
name: reviewed-skill
description: 使用审核过的说明与参考资料
jiaclaw_resources:
  - path: references/guide.md
    sha256: <审核文件原始字节的64字符小写SHA-256>
---
需要细节时读取目录中声明的参考资料。
```

配置 `[tools.skill_read] enabled=true, resources_enabled=true` 显式注册独立工具 `skill_resource_read`；两项缺省都为false，resources_enabled不能单独启用。它仍需要原请求 enabled_tools授权，资源正文和技能正文都不能扩大权限；租户协议仍仅datetime_now/json_query。缺省关键词行为和只启用正文读取的已有配置兼容。

每轮摘要目录包含声明的 path/sha256，启动与重载只解析声明，不打开参考文件或提前注入其正文。工具仅接受 name、content_sha256、path、resource_sha256 四个参数。每项路径只能是 references/ 下的规范相对路径，最多256 UTF-8字节/16组件，不允许空组件、绝对路径、点路径、反斜杠、冒号、首尾空白/控制字符，声明路径唯一。资源hash绑定原始文件字节，正文hash绑定现有已解析正文；两者都不证明来源、签名或安全性。

实际worker在注册表短读锁内选择当前技能、正文版本和匹配的资源声明，然后在配置工作区一级技能目录下通过现有目录能力读取，不通过模型路径或环境路径打开外部文件。资源可以在选择后被重载撤销，已选中的读取不追溯撤回，但返回字节仍必须匹配所选hash。选择前替换正文/改声明/撤销技能会拒绝旧参数；磁盘资源即使未重载也必须匹配已加载声明的hash，否则拒绝。先读磁盘再核验，只有审核版本的字节可以成功返回。

参考文件只允许单链接普通UTF-8文件，拒绝父/叶符号链接、硬链接、FIFO、目录、设备与无效UTF-8。每次最多128 KiB，实际读取增长超限拒绝；JSON字符串扩展后超过原生共享256 KiB输出预算时在成功返回前拒绝，不截断。读取复用文件工具的八个共享I/O槽，实际blocking worker持有许可，调用者取消/超时不提前释放；不会持注册表锁进行文件I/O。所有失败属于只读 no_effect，可由模型在原预算内反馈，不能当作外部写入的效果证明。

本能力交付声明、版本核验和按需参考文本读取，不执行脚本、不下载或安装技能。来源锁文件、安装更新/撤销流程、经验提炼、真实供应商选择质量、跨租户授权和durable恢复仍分别待实现或认证。本机协议fixture和源码边界测试不认证这些能力。
