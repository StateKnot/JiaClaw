# 管理员确认已登记技能的新来源版本

`jiaclaw skills set-source <一级目录> --repository <HTTPS来源> --revision <固定Git对象ID> --skill-sha256 <完整SKILL.md原字节SHA256> --if-manifest-sha256 <已审查原锁SHA256> --config ...` 只修改已登记、已停用技能的来源声明。所有参数必须明确提供；来源不允许用户名、密码、query、fragment，Git对象ID为40或64位小写十六进制。管理员须自己审查来源、固定版本和原始文件；命令不会联网证明来源，来源声明不是签名或供应商认证。

操作顺序：用既有 `skills set-enabled` 条件停用，另外成功重载服务确认不再加载该技能；在原目录准备并审查新文件，计算完整 `SKILL.md`（含frontmatter）的SHA256。审查当前磁盘锁，使用其原字节hash请求 `set-source`。命令要求目标仍停用且来源声明确有变化，在工作区能力内读取、解析并核对目标原始正文，然后验证完整候选启用目录。普通文件、链接/硬链接/FIFO、128KiB/文件、64项/2MiB启用目录和256项扫描边界沿用原合同。目标正文额外至多读取128KiB；参考文件原始字节在实际按需读取时另行核验，来源确认不认证整包引用内容。

原锁读取、条件检查、目标读取、完整候选扫描、私密暂存sync、同目录rename与目录sync共用现有非排队工作区writer。缺锁、未登记、启用中、过期hash、相同来源、无效来源/正文/摘要和候选目录错误均不提交，保留原字节；v2启停值、全部其他来源声明保留。成功仅返回 `disk_policy` 和 `runtime_applied:false`，目标仍停用。之后必须另用新锁hash明确启用、成功认证重载并GET原服务，才可确认运行表已采用新版本。

提交前失败不发布；rename后目录同步错误可能已提交，须先检查原磁盘，不自动重试。hash是内容条件，不是操作代次/ABA检测。协作锁不是独立ACL，不阻止非协作本机编辑或授权文件工具改写磁盘；启用和重载会再次检查实际正文。该命令不下载、安装、删除或回滚文件，不自动启用/重载，不提供模型或HTTP写入口，不扩大租户和工具权限，不取消已选择工作或抹除历史。
